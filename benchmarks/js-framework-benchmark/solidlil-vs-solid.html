Reusable solid-js replacement. Export names stay stable. Core is 118 B smaller under Brotli-11 (8,433 vs 8,551). That is a library-surface result, not a claim that every app compresses better.

Race 2 — closed-world keyed app

Whole program, compiler size-first, Brotli-11. Unused APIs disappear and retained names may be mangled. This is the mission-aligned test for “replace Solid in an application.”

Compatibility and exclusions

Runtime parity is gated separately from JSX/LSX compiler parity.

In scope and passing

  • 469 / 469 unchanged upstream Solid candidate tests (26 files).
  • 135 / 135 Core, Web, and Store exports with differential evidence.
  • LSX: components, spreads, For / Index / Show / Switch, Dynamic, Portal, SVG/MathML, Suspense, ErrorBoundary, unmount.
  • Keyed browser contract: create, update, select, swap, remove, clear.

Explicitly excluded

  • SSR and hydration — need a coordinated server runtime.
  • C / native backends — no Solid Promise / exception ABI yet.
  • Full 73-export Web bundle as a size win (currently +12 B Brotli).
