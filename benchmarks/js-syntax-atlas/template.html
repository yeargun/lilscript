Compression laws worth stealing

These are optimizer tactics, not blind rewrite rules. The atlas below gives the evidence and the boundary conditions.

Optimize the bundle, not the node.

A local winner often stops winning after a fixed dictionary is introduced.

Long built-in names can amortize.

Object, Array, prototype, length, return, and method names become cheap after repetition; fresh punctuation-heavy control flow may not.

Give raw, gzip, and Brotli separate objectives.

Their winner sets disagree often enough that a single source-length heuristic throws away real bytes.

Model semantic preconditions explicitly.

Holes, getters, proxies, callback arguments, iterator closing, NaN, -0, Array species, this, hoisting, and promise timing are common rewrite landmines.

Repeated shapes are a currency.

A compiler can intentionally standardize loop or branch spelling across a file, accepting a tiny local raw loss to build a better dictionary.

Do not spend runtime to save transfer bytes blindly.

map-for-effects, table dispatch, JSON cloning, Set construction, spread, and bind can allocate or change complexity. Size and execution need separate gates.

A weird-tactics queue for LilScript

Ideas suggested by the races, deliberately left as research directions rather than compiler changes.

Whole-file spelling portfolios

Keep several proven-equivalent loop, branch, literal, and mutation forms alive until mangling finishes; score combinations against the final target codec instead of committing node by node.

Vocabulary standardization

Prefer one repeated structural dialect across a bundle—perhaps more if, one loop header, or one object-copy form—when dictionary reuse repays local raw losses.

Warm-token marginal scoring

Price a candidate as a delta against nearby or full-bundle bytes. Cache the codec state or rescore bounded regions; isolated snippet streams are mainly a diagnostic.

Built-in break-even search

Let long spellings such as Object.create, slice, prototype, and function compete after repetition. Brotli’s dictionary can reverse obvious source-length choices.

Lexical shape competition

Choose quote kind, number radix/exponent, Boolean/undefined spelling, key quoting, RegExp construction, and semicolon/comma layout using actual surrounding bytes.

Alias portfolio search

Introduce aliases for repeated property paths or built-ins only after jointly pricing declaration cost, call-site savings, mangled name choice, and gzip/Brotli reuse.

Prototype representation races

When the ABI proof permits it, compare class syntax, prototype assignment, object-literal __proto__, Object.create, and closure factories as complete families.

Proof-keyed candidate menus

Generate risky compact forms only when analysis proves the exact preconditions: dense arrays, pristine built-ins, no getters/proxies, stable methods, finite numeric ranges, ignored results, or closed-world prototypes.

Codec-specific artifacts

Raw, gzip, and Brotli outputs should be allowed to differ. The atlas records enough disagreement that forcing one universal JavaScript spelling is an avoidable constraint.

Runtime veto after size search

Reject candidates that add harmful allocation or complexity—map-for-effects, repeated table creation, JSON cloning, Set setup—unless the surrounding workload makes that cost acceptable.

What can actually be shared?

Pure ECMAScript does not specify execution speed or allocation count, but it absolutely exposes identity, evaluation order, property-read counts, iterator hooks, live bindings, and direct-eval scope. Matching printed output is not enough; 32 focused executable probes treat all of those as behavior.

Primitive values: often yes

Numbers, strings, Booleans, BigInts, null, and undefined have no object identity. Reusing a computed primitive is exact only when its inputs are stable and its evaluation is pure and stays in the same ordering region.

Symbol: the primitive exception

Every Symbol() call produces a distinct identity. Symbol.for() deliberately shares through the global registry. One cannot replace the other.

Objects and arrays: no generic sharing

Equal contents do not erase ===, mutation coupling, prototypes, descriptors, WeakMap keys, proxies, or retention. Object.freeze prevents writes; it does not remove identity.

Functions, RegExps, and Promises: also no

Functions carry identity and properties; global/sticky RegExps carry lastIndex; Promises remain distinguishable even with equal settlement. Factories may preserve freshness, but add calls and closure behavior.

Non-escaping aggregates: potentially removable

If whole-program analysis proves an object never escapes to a call, eval, proxy, weak reference, or reflection, scalar replacement can preserve every reachable language result while deleting the allocation.

Tagged templates: site identity is data

A tag receives one frozen template object cached per syntactic site. Merging identical sites into one loop/helper changes the object passed to the tag.

Are extra sub-closures transparent?

Usually not. They are candidate representations only inside a closed, proven-safe region.
