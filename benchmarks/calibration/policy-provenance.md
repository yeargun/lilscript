# Generic policy and historical provenance

The compiler never branches on a library name, source path or benchmark ID.
C3 reviewed every entry of [the former NO3 ledger](historical-no3.json).
Its measurements remain history, not predicates or universally valid priors.
`tests/no3-allowlist.json` is empty and its source gate remains enforced.
This cleanup changes comments and evidence, not generated bytes or schedules.

| Former justification | Current generic rule or choice | Remaining policy owner |
|---|---|---|
| `js/families.rs` statement/quote seeds and challenger order | Every alternative is available to every objective; complete-artifact exact judging admits a change. Seeds and order are inherited priors, not proved rankings | Q3 calibrates priors; G3 expands site choices |
| `js/mod.rs` loop heads and logical statements | Formation records alternative spellings; terminal search measures complete artifacts | G3 |
| `js/mod.rs` default checks | Checked defined-argument facts and complete private call uses prove the default cannot execute. Remove the check while retaining supplied arguments | S1 extends propagation, not this proof |
| `js/declarations.rs` declaration joining | No read crosses the moved uninitialized declaration's TDZ; initialization remains undefined. The bounded backward scan is generic | G3 |
| `js/inline.rs` stable/repeatable arguments | Evaluation order and stability prove substitution. Single-use removal and bounded repeated substitution are separate paths | S3 replaces the conservative duplicating prior with judged alternatives |
| `js/rules.rs` expression-body limit | Six nodes is an inherited compatibility bound on duplication, not a semantics rule or calibrated optimum | S3 |
| `js/statements.rs` peephole ordering | Rules preserve evaluations/exit behavior; spelling families are codec judged. No source identity orders an individual compilation | G3/Q3 |
| `js/tables.rs` columns, dictionary, front coding and decoder sharing | Literal graph equality establishes legality, including enumeration order. Equal complete schemas share decoders; exact artifact scoring decides representations | Q4 |
| `program/javascript_methods.rs` receiver adapter formation | Each callback retains its own call site, receiver binding, strictness and captured environment; legality conditions precede formation | S3 runtime qualification for changes |

## Audited bounds

An analysis safety limit may conservatively refuse an optional optimization.
It cannot license a semantic change. A quality prior may limit exploration;
its value is not advertised as optimal. Resource ceilings remain separate.

| Source / value | Classification and basis | Control / change discipline |
|---|---|---|
| `js/rules.rs` `INLINE_LIMIT=6` | Compatibility quality prior, inherited from historical measurements recorded above | `policy.tactics.inlining`; S3 owns replacement, not C3 retuning |
| `js/inline.rs` `SITE_DEPTH=MAX_NESTING/2` | Structural safety bound leaves nesting room for a moved body | Derived from verifier limit; no library input |
| `js/inline.rs` evaluation walk 1024 nodes | Bounded optional analysis; refusal retains the call | Logical-work ceiling also applies; S3/Q2 own scaling |
| `js/rules.rs` `ROUND_CEILING=64` | Defensive termination bound on potentially interacting edits | A hit must not be reported as a proved fixed point; Q2 scheduling |
| `js/declarations.rs` `JOIN_WINDOW=16` | Bounded local lookback; missing a join preserves meaning | G3 alternatives/Q2 work bounds |
| `compilation_policy.rs` `WalkSchedule` prefixes 8/24/all, exact budgets 2/4/6/8/12/unbounded | Inherited effort prior; 13 gives fixed-point walks within explicit resources | `effort.level`, resource limits; Q3 calibrates each objective |
| `WalkSchedule` raw/gzip margin 0, Brotli margin 150 | Heuristic proxy pruning, never a correctness bound or guaranteed final-byte bound | `policy.search.proxy_pruning = on/audit/off`; C3 reports misses and path loss; Q3 owns margin changes |
| `compilation_policy.rs` structural proposals/probes/beam/retention | Central versioned effort policy, bounded by resolved service resources | `effort.level`, `policy.resources`; receipts report admission/stops |
| `js/families.rs` seeds / challenger order | Compatibility search priors; decisions ultimately use exact requested bytes | Family permissions and effort gate discovery; Q3 generic calibration |
| `compilation_policy.rs` deferred naming starts at 14 | Measured expensive path exploration. Explicit `on` at 13 remains available; `off` vetoes | `policy.search.deferred_naming_starts`; retained small-corpus/port evidence precedes C3 |

No numeric prior changed in C3. This is intentional: a corpus and audit cannot
retroactively prove its inherited settings best. Q3 must use the frozen
training folds, work costs and independent evaluation protocol before changing
them. Safety limits can be changed for demonstrated scaling problems with
corresponding refusal/resource tests; they are not codec tuning parameters.
