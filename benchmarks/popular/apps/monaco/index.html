How both production builds are made

JS: esbuild minify of monaco-editor ESM plus its workers, then lilscript-codec Brotli-11 / gzip-9 (stock zlib 1.3.1 / official Brotli C 1.1.0). Lil: LilScript compiler of the runtime editor plus the monaco-editor-core catalog (992 modules compiled as reusable libraries so class methods stay in the artifact), one js-host, same workbench chrome, esbuild minify, same codec. The HTTP server sends Brotli-11. Lil language hosts remain compiled LilScript for JSON/CSS/HTML/editor workers. Both pages load the same Microsoft ts.worker (typescriptServices.js) so TypeScript and Solid TSX use the real language service.
