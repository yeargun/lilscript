# Release 2026-09-24: the one compiler across the goal ports

This is plan step M2.9. Twelve of the thirteen goal ports were rebuilt by one pinned
compiler and pushed, and their Pages sites are live (`https://yeargun.github.io/<port>/`).
motionlil was not released (§4).

**Headline.**
- **Against the last release:** the twelve headline files went from 288,827 to 247,172
  Brotli (−41,655, −14.4%). Nine of the twelve are smaller; markedlil, mdast-util-to-hastlil
  and remark-rehypelil are larger.
- **Against Terser, Oxc/Rolldown, esbuild and upstream's minified file:** 11 of 12 win on
  Brotli. katexlil is 18 bytes above upstream's `katex.min.js`, and it is a tie against
  its pinned Terser bar.

## 1. What changed since the last release

The last release's `dist/` files were built by the old compiler route in early September:
LilScript `f504c93` on 2026-09-02, and `4dc4e33` for the 2026-09-10 page refresh.

- **One compiler.** The old route (typed CFG/SSA IR, IR optimizer, string emitter, text
  peephole) was deleted on 2026-09-23/24 (plan phase M1). `src/` went from 362K to 187K
  lines, `--backend` is gone, and 61 retired configuration keys now warn or refuse.
  - The architecture is [future-architecture.md](../future-architecture.md).
  - The plan and its progress are [migration/index.md](../migration/index.md).
  - The state of the checkout is [current-status.md](../current-status.md).
- **Port rewrites in the ports' own repositories.** The rewrites that lived as
  `finer/port-migrations/*.patch` are committed to each port (katexlil's patch touched 61
  `.lil` files, micromarklil's 52), along with the integrated zod rewrite. This is M12.1,
  brought forward into M2.8.
- **Config cleanup.**
  - Every key the compiler reports as "no effect" was removed from the port configs. Each
    output is byte-identical before and after, and no optimizer knob was added.
  - Configs that existed only because of the old route are deleted: katexlil's
    `lilscript.mhchem.toml` (mhchem now builds in 1.4 s, and its file went from 9,058 to
    8,018 Brotli), and posthoglil's `lilscript.closed.toml` and `lilscript.packs-safe.toml`.
- **No post-minifier on eight ports.** markedlil, jquerylil, micromarklil,
  mdast-util-from-markdownlil, remark-parselil, mdast-util-to-hastlil, remark-rehypelil
  and react-markdownlil ship compiler output only. Their CJS and browser files are the
  same program with the export clause swapped for a small text wrapper. jquerylil already
  worked this way; on the other seven, esbuild used to reprint these files. The remaining
  esbuild steps are listed in §4.
- **Evidence on every site.** Each site publishes the pinned compiler and its compile time.
  A clean source build of the release commit, run on this host, reproduced `dist/` byte
  for byte.

**What each bar is.**
- **katexlil.** Terser, Oxc and esbuild run over katex@0.16.22's published npm graph.
  - `import "katex"` loads the unminified `katex.mjs`: 119,059 Brotli.
  - `katex.min.js` is upstream's own minified UMD. It is on the CDN and reachable as a deep
    import. Without our 73-byte banner we are 62,698, still 12 bytes above it.
  - A stretch bar, built from the Flow sources with esbuild and Terser, is 61,758. We are
    +946 against it.
- **markedlil.** The bars cover marked@18.0.10's parse-only surface (Lexer, Parser,
  Tokenizer, Renderer), which is what the port implements. marked's published
  `marked.esm.js` (11,907) is minified but carries the full API (`use()`, hooks,
  `walkTokens`), so it is shown for context only.
- **posthoglil.** The bars cover posthog-js@1.418.10's kernel modules. The SDK's own
  bundles cover the whole SDK, so none is comparable. A build from the original source
  (`3508c05`) with Terser gives 5,639.
- **jquerylil.** The official `jquery.min.js` 3.7.1 is the strongest bar. Terser, Oxc and
  esbuild run over jQuery's Git source at the 3.7.1 tag, bundled as ESM.
- **zodlil.** The bar is zod@4.4.3 cut to the 181 `z` members the port shares, English
  locale only. Its core namespace carries about 1.2K Brotli of surface the port lacks, and
  the port's extras count against us. zod ships no minified build.
- **micromarklil, mdast-util-from-markdownlil and remark-parselil.** The bars are the
  official Node graph, which ships the character-entity table as the ports do. Upstream's
  browser graph decodes entities through the DOM and ships no table:
  - micromark: 12,945, which we lose by 9,121.
  - mdast-util-from-markdown: 13,336, which we lose by 8,972.
  - remark-parse: 13,399, which we lose by 8,987.

  These ports have no DOM-decoder build yet. react-markdownlil has one.
- **unifiedlil.** Terser (3 passes) runs over the unified@11.0.5 graph built from source.
  Terser over the npm graph gives 4,425.
- **mdast-util-to-hastlil and remark-rehypelil.** The bars are the npm graph. Terser over
  the Git source gives 4,949 and 5,000.
- **react-markdownlil.** The bars are upstream's browser graph with React external. The
  Terser column is Git source `44d2e4a` plus Terser 5.51.2; Terser over the npm graph gives
  31,082.
- **\*** This Oxc bar was measured for this report with Vite 8.2.1's `minify` (Oxc; module,
  compress, mangle) over the same graph as the Terser bar. The same recipe reproduces
  remark-parselil's Rolldown 1.2.5 row byte for byte (23,339).
- **†** The zod package is `zod.core.js`, `compat.js` and `index.js`, each compressed on
  its own, as they load. The previous release had seven files.
- **‡** motionlil's `full.js` is from the parked release commit. It is esbuild plus Terser
  over our output, not compiler-written, so rule 6 gives it no size claim. Against the
  port's own strongest recipe (esbuild plus Terser with `_`-property mangling, 39,871) it
  would be −4,704.

## 4. Caveats

- **Files the compiler did not write.** Plan rule 6 gives these files no size claim. They
  are labelled on each site and owned by M12.2, because the compiler has no CJS or browser
  target yet.
  - **katexlil:** `katex.cjs`, `katex.umd.js`, `katex.min.js` and the contrib `.cjs` and
    `.min.js` files are esbuild re-bundles. The three core files lose to the Terser bar by
    576 to 619. The ESM also concatenates upstream's font-metrics data module (57,656 raw,
    unchanged).
  - **posthoglil:** `posthog.cjs`, `posthog.umd.js` and the five pack `.cjs` files are
    esbuild reprints.
  - **zodlil:** `index.cjs` is an esbuild CJS bundle. `compat.js` is hand-written and not
    minified (314 Brotli). Bundled by esbuild without minification, the package is 31,732,
    a loss of 2,295.
  - **unifiedlil:** `unified.cjs`, `unified.umd.js` and `vfile.cjs` are esbuild format
    conversions.
- **Not released: motionlil.**
  - Its local main had diverged from GitHub: 3 unpushed commits against 19 remote commits
    from 2026-09-10/11 that touch 96 source files. A trial merge gave 105 conflicts.
  - The finished release is parked at `0eeca0c` on the local branch
    `release/aa2052f0-integrated-on-69cd2cf`. It is green: tests 9/9 and 0 harness
    regressions.
  - It must be re-integrated onto origin/main.
  - Six of its entries (`full.js`, `animate.js`, `animate-mini.js`, `mini.js`,
    `index.bundle.js`, `motionlil.global.js`) and all ten `.cjs` files are still esbuild
    plus Terser output.
- **Other ports.** The 14 other maintained ports were not rebuilt; that is M2.8. No npm
  package was published.
- **Tests.**
  - Every released port's suite passes with the pinned compiler.
  - Three entries in `tests/ports/expected-failures.json` now pass and must be removed:
    mdast-util-from-markdownlil and remark-parselil (the site receipt test), and
    react-markdownlil (the build failure).
  - Known gaps:
    - **markedlil:** the migration patch drops the closed-lane assertion that option keys
      are mangled, because the compiler renames no properties (M9.6).
    - **jquerylil:** the differential against jquery@3.7.1 is better than the previous
      release but not at parity: core 185/187, dom 5,615/5,630, effects 182/183,
      event 280/291.
    - **react-markdownlil:** the official suite passes 85/91 on the production build. The
      six failures are development-only assertion tests.
- **Regressions against the previous release.**
  - markedlil: +24 Brotli, and +1,665 raw for its raw-objective compile.
  - mdast-util-to-hastlil +320 and remark-rehypelil +299. Their diagnostic closed lanes
    grew to 5,740 and 5,885.
  - katexlil's contrib files grew by 13 to 80 each, and all five lose to Terser over
    upstream's contrib files, by 10 to 605.
  - posthoglil's autocapture, replay-core and surveys packs grew by 15 to 41, and
    error-tracking loses to Terser by 749.
- **Closed world.** The compiler renames no properties (M9.6). The closed build therefore
  equals the open build (katexlil, markedlil, unifiedlil) or differs only in optimizer
  settings.
- **Speed.**
  - zodlil parses 5.8× slower than zod in Chromium, down from about 1.5×. The rewrite
    removed zod's `new Function` fast paths.
  - katexlil, mdast-util-from-markdownlil and unifiedlil are about 3–12% slower than
    upstream.
  - The other ports that were measured are at parity or faster.

## 5. What is next

1. **M2.** M2.1 has landed: CI has been green since `335bcf15`, for the first time since
   2026-08-25. Next are re-integrating motionlil, the M2.8 fleet baseline on one binary,
   and the oracles, the admission parse and the differential (M2.3–M2.5, M2.7).
2. **M3–M5.** Honest configuration and a delivery contract, whose compiler-written CJS and
   browser files remove the last esbuild steps (M12.2). Then checker identities and the edit
   and selection machinery.
3. **M6–M7.** The fact spine and the program rules. M6.1–M6.3 and M7.2 landed after this
   release's binary, in `ff27361f`.
4. **M8–M9.** Canonical formation, source maps (M8.6), choices, naming and layouts, and
   property renaming (M9.6) for the closed world.
5. **Remaining losses (M12.3).**
   - motionlil is not yet compiler-written.
   - katexlil is +18 against `katex.min.js`.
   - The micromark family is about +9K against upstream's browser graph and needs a
     DOM-decoder build.
   - zodlil's esbuild-bundled package is +2,295.
   - katexlil's contrib files and posthoglil's error-tracking pack still lose.
