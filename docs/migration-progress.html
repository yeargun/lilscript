V-01implemented

Final artifacts are admitted before scoring.

Syntax, bindings, exports, imports, free names, ABI, properties, ranges, feature floors, and live lowering obligations are checked before a codec can choose the output.

V-02landed

Terminal renames preserve identity.

Whole-artifact remaps require total binding resolution, reserve fixed descendant names, and fail closed when the bounded name alphabet is exhausted.

V-03landed

Ordinary objects keep assignment semantics.

Literal collection is legal only with an explicit pristine-builtins contract; inherited setters and __proto__ cannot be silently erased.

What changed

One-way authority from semantics to selected bytes.

A smaller result is allowed to win only after source facts have established that it is legal. Codec cost influences profitability, never meaning.

01 Source semantics Types, effects, identity, ownership, and escape.
02 Immutable contract World, ABI, syntax floor, effects, and assumptions.
03 Typed IR options Legal representations keep their incumbent.
04 Registry recipes Bounded candidate families and deterministic order.
05 Artifact admission Final bytes prove syntax, identity, ABI, and obligations.
06 Exact codec score Raw, gzip, or Brotli selects among legal artifacts.

Already centralized

The registry classifies all 77 JavaScript emission option fields and names 48 scored emission families. Terminal JavaScript now has shared admitted scoring rather than repeated local acceptance sequences.

Still transitional

Generated JavaScript is still string-produced, and some target folds reparse it to recover identity. Phase 3 replaces that fragile boundary with a minimal hygienic target tree.
