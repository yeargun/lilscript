## Current Order

1. Make large-library evidence and selected recipes replayable.
2. Strengthen contract, expected/observed ABI, and pre-score final-byte checks.
3. Recover legal incumbent artifacts for current regressions.
4. Consolidate existing policy and acceptance paths without adding choices.
5. Introduce the minimum hygienic target-JS representation.
6. Close library losses with reusable proofs and measured interactions.
7. Expand search only where evidence shows a reachable miss.
8. Delete superseded paths and certify release.

The standing canonical, generated, algorithm, codec, and external semantic suites
run throughout. A clean architecture that regresses a supported selected-metric
artifact or weakens semantics has not completed a phase.

## Working Rule

Classify every loss before coding:

1. correctness/identity/ABI bug;
2. old legal incumbent became unreachable;
3. admitted family was starved or poorly ordered;
4. missing reusable language/analysis proof;
5. port still encodes JavaScript glue;
6. genuinely dynamic boundary where the compiler lacks authority.

Do not turn the last three into package-specific target folds.
