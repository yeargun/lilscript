# Implementation status, 2026-09-20

> History: the status page as of 2026-09-20, written while two compiler routes shared one binary; the old route was deleted on 2026-09-23 (plan M1). Kept as a record; the current page is [current status](../../current-status.md).

**Updated 2026-09-20; migration is in progress, not certified.** [Compiler design](../../compiler-design.md) remains the unchanged target. The single [migration plan](../../migration/index.md) contains all fourteen steps and their progress; no complete milestone is verified. Public-JS boundary decision D2 remains open.

The default compiler still uses its existing control-flow pipeline. Public `compile_source_semantic` / `compile_path_semantic` APIs and CLI `--backend semantic` now expose the supported semantic slice explicitly, without silent fallback. It uses checked units, facts, source edits, representation choices and existing bounded JS search/native owners. LSP, playground and Lilpack routing remain legacy. The broader language, delivery and architecture gates remain open.

Current bounded work adds immutable-record admission for JS and native C/header artifacts, exact-score reuse, policy-aware search budgets and a structural compression-interaction regression. Complete recipe descriptors and checked rewrite history survive candidate/search disposal, including frozen producers, without per-naming copies. The migrated example and default semantic service use one factory-finalized checked-source session. The earlier broad [source-pinned checkpoint](../../../benchmarks/migration-results/2026-09-19-artifact-service/README.md#parse-once-module-discovery) passed 1,065 Rust library checks, CLI delivery and original direct/search/edit/native consumers. All 15 compared delivered JS/C files matched its previous checkpoint. Partial frontend admission, recipe replay, complete language support and final gates remain open; this is not milestone certification.

The library evidence tools now observe original Node/Vitest cases and actual production loads.
