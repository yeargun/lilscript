## Decisions recorded

- **There is one compiler** (owner, "theres single backend obviously"). The route built since the 2026-09-18 reset is that compiler. The old route is deleted, not kept as an alternative. "Backend" from now on means a target (JavaScript or native C), never a compiler route.
- **Both the language and the compiler are designed for size**: Brotli first, raw and gzip selectable, as global an optimum as the budget allows, cross-target (JavaScript and native C).
- **Learn from Closure ADVANCED, Terser, Oxc, Rolldown and esbuild; copy none of them; beat all of them.**
- **No glue.** Every mechanism is by design, generic and sound.
- **Size over runtime performance** ("bundle size is lil more important"): runtime becomes a reported lane, not a gate, unless a library contract declares one. This supersedes the 2026-09-02 per-port performance gate in general; the plan records the known runtime regressions.
- The architecture is `docs/future-architecture.md`; the plan is `docs/migration/index.md`.
