Completion rule

No partial credit

Complete means every tracked packages/*/src TypeScript or TSX file at pinned Vue v3.5.42 has one hash-verified, non-placeholder LilScript counterpart at its deterministic mirrored path (or strict declaration-only handling for a type-only file), module responsibility and algorithms are preserved without JavaScript delegation, every listed package entrypoint and format is independent of Vue implementation code, all applicable unchanged upstream tests pass, public runtime and declaration surfaces match, every required actual-project scenario produces a smaller Brotli-11 candidate bundle from identical application source and build settings with matching execution, and benchmark confidence bounds show no material regression.

Inspect the complete source-derived inventory in evidence.json. Generated presentation text is not itself a benchmark or compatibility result.
