Application evidence

Measured project comparisons

Five behavior-equivalent applications are built as readable ecosystem JavaScript, esbuild output, Closure ADVANCED input, hand-specialized JavaScript, and LilScript. Every JavaScript artifact and native LilScript executable must pass the same output contract before measurement.

Application specialization is not library compatibility. The reactive, event, and Motion projects exercise real npm packages in the ecosystem lane; their LilScript versions implement the measured app contract, not each library's complete API.

Method

Reproducible, scoped evidence

Measured on 2026-08-06 from compiler revision f3bed41 with Node 20.12.0, esbuild 0.28.1, Closure Compiler 20260803.0.0, deterministic gzip level 9, and Brotli quality 11. Runtime is the median of nine fresh Node processes after two warmups, so it includes process startup and should detect broad regressions rather than prove engine-level causality.

Complete source sizes, per-lane deltas, expected output, and interpretation limits are checked in under benchmarks/apps/RESULTS.md.
