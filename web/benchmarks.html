Scoped evidence

Comparable compilers, separate ecosystems

Compiler tables use readable JavaScript and LilScript programs with the same app algorithm and abstraction scope. Closure receives the exact JavaScript reference. Real npm packages are built independently with Vite 8 and never enter compiler totals.

Matching one stdout contract catches regressions for measured inputs; it does not prove complete semantic or library compatibility. Hand-specialized JavaScript is an optimization oracle, not source given to either compiler.

Compatibility status

Motion 13 is not implemented yet

The current npm package exposes 312 root exports and spans approximately 64,000 source lines across Motion, Motion Utils, Motion DOM, and Framer Motion. The independently published two-export @motionone/easing package now has a complete measured port, but that does not imply compatibility with the current Motion DOM engine.

The versioned scope, missing language/platform facilities, port sequence, and no-false-claim gates are documented in docs/motion-compatibility.md.
