LilScript is a typed, compression-first language. The compiler owns types, optimization, mangling, and codec search. Lilpack is the bundler that compiles .lil modules and delivers them through Vite 8. They are not the same thing.

In one minute

LilScript
The language, type system, SSA optimizer, and JavaScript/native backends. Source of truth is .lil, not TypeScript.
Lilpack
The delivery interface: mixed .lil / JS / TS graphs, HMR, and production bundles. It does not replace the compiler.
Projects
Lilastro, SolidLil, and Lastro sit on that path. They prove pages, reactivity, and a full app — they are not the language.

Start with LilScript source. Add only the project layer the application needs. Lilpack owns delivery at the edge of the graph.

  1. 01 · languageLilScript

    Types, semantics, whole-program optimization, JavaScript and native output. Gzip and Brotli are scored on complete artifacts.

    Static page structure or a Solid-compatible reactive DOM, still authored in LilScript and LSX.

  3. 03 · deliveryLilpack

    Compiles the module graph, keeps HMR honest, and ships the compiler’s JavaScript. It is not a second optimizer stacked on Terser.

How to read the numbers

Raw shows emitted code volume. gzip is common transfer compression. Brotli is a stronger production transfer codec. A result matters only after behavior and scope match.
