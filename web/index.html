LLilScript

Language · compiler · Lilpack

Write LilScript. Ship less JavaScript.

LilScript is a typed, compression-first language. The compiler mangles, reshapes, and scores a complete JavaScript artifact against the codec you pick — gzip, Brotli, or raw size. Lilpack is the Vite-based delivery path: fast reloads, a language server, the usual editor tools.

class Vector {
  float x;
  float y;

  init(float x, float y) {
    this.x = x;
    this.y = y;
  }

  float lengthSquared() {
    return this.x * this.x + this.y * this.y;
  }
}

int[] values = [1, 2, 3, 4];
auto doubled = values.map((int value) => value * 2);
int sum = 0;
for (int i = 0; i < doubled.length; i++) {
  sum += doubled[i];
}
Vector vector = new Vector(3.0, 4.0);
if (vector.lengthSquared() == 25.0) {
  print(`sum=${sum}`);
}

01 · How it gets smaller

Change the program’s shape. Measure the result.

LilScript optimizes a typed program before emitting JavaScript, then scores the complete artifact under the chosen compression objective.

Objects

Flatten when it is safe

Scalar replacement and method devirtualization can remove private allocations and calls. Public objects, observable identity and host-facing contracts constrain these transformations.

Names and data

Optimize owned properties

The compiler can rename private properties and identifiers, simplify constant tables, and evaluate alternate layouts. Public and external property names retain their JavaScript contract.

Objective

Raw, gzip, or Brotli

objective.codecs selects the measured target. Raw, gzip and Brotli can choose different artifacts. Our comparison rows use an independent compilation for each objective.

06 · Tooling

The language has to feel like a web toolchain.

Closure’s Advanced mode is the closest ancestor. The Java stack around it is slow and awkward for everyday web work. LilScript is being built so reload, analysis, and editor support sit on par with the rest of the ecosystem.

Lilpack

Development reloads

lilpack dev turns expensive search off and keeps HMR honest. Production uses the project lilscript.toml.

Editor

VS Code + LSP

lilscript-lsp and the repo extension: highlight, diagnostics, completion, hover, rename, format.

Config

A lot of knobs

Codec, priority, mangling, inlining, layouts, chunks. The language page walks the ones that change behavior.

07 · Read the scope

A benchmark is a specific claim.

Full-library, selected-API and compatibility-runtime results answer different questions. Check the linked API boundary, external dependencies and test coverage before choosing a package. Compiler transformations can reduce transfer size while making a workload slower; measure the workload that matters to your application.
