These are libraries and apps we rewrote in LilScript to see what the compiler actually does. Numbers are independently measured gzip-9 and Brotli-11 bytes of the selected JavaScript, scored with the same stock zlib / official Brotli binaries. On the 15 currently comparable landing rows, the median result is 7.7% smaller under gzip and 7.5% smaller under Brotli. Zod is visible but excluded after its package surface audit invalidated the old core-only size row.

Mangling contract. On reusable-library rows, mangle: true means identifier mangling only. Oxc renames variables and private class fields; Terser property mangling is a separate option and is off here. Public ESM names and documented object keys must survive, and behavior gates run on the measured artifacts. Property mangling appears only on explicitly labeled closed-world app lanes or on LilScript-owned internals whose public ABI remains named. If Function.name, arity, or constructibility belongs to a library contract, the verifier must pin it too. See the Oxc mangling documentation and Terser API reference.

Parse API

marked 18.0.13 package, scored without the extension system.

The 18.0.13 package exposes the parse API, live option methods, GFM, and CommonMark HTML, with 660/660 against marked@18.0.10. This port has no use(). Official JavaScript is the parse-only 18.0.10 sources, then Oxc and Terser with identifier mangling enabled or disabled; property mangling is off. The published LilScript artifact is the compiler-selected ESM — not bundled, not post-minified, and still smaller on raw, gzip-9, and Brotli-11 than either minifier, while parsing the same corpus faster in Chromium.

Zod 4.4.3 · size audit open

The behavior result remains; the size win does not.

zod@4.4.3 rewritten in LilScript and published as @itslil/zod. The adapted official suite is 1,353/1,353, but the old 34,152 B Brotli figure measured only zod.core.js while the official lane bundled the full zod/v4 entry. Linking the actual package entry produces 62,763 B gzip and 52,583 B Brotli, before any claim about parity. That package exposes 192 ESM names versus 240 on the official entry, so no compression rate is published until the boundary matches.

Six scoped lanes · posthog-js 1.418.10

A capture kernel plus five independently measured packs.

UUID, flag utils, cookie identity, request routing, token and bucketed rate limits, queue batching, bot detection, and portable helpers — not the published PostHog IIFE. Official JavaScript is that kernel, then Vite 8 Oxc, Terser, and esbuild. The current Brotli-scored compiler artifact is larger than Oxc on this compiler. Autocapture utilities, replay core, surveys, error tracking, and OTLP now have separate public surfaces and tabbed comparison lanes. The two browser packs are 24.4% and 18.6% smaller than Oxc on Brotli; the lab reports every pack's wins and losses without folding them into the kernel result.
