Same work. Count the bytes.

These are libraries and apps we rewrote in LilScript to see what the compiler actually does. Numbers are independently measured gzip-9 and Brotli-11 bytes of the selected JavaScript, scored with the same stock zlib and official Brotli encoders. Across the 11 published library ports that vote, the median is 5.9% smaller under gzip-9 and 7.0% smaller under Brotli-11 than the bar named on each card.

Mangling contract. On reusable-library rows, mangle: true means identifier mangling only. Oxc renames variables and private class fields; Terser property mangling is a separate option and is off here. Public ESM names and documented object keys must survive, and behavior gates run on the measured artifacts. Today’s compiler renames no properties at all; property renaming for the closed world is being rebuilt, and the Motion lane that uses it applies it to both sides with esbuild and Terser. If Function.name, arity, or constructibility belongs to a library contract, the verifier must pin it too. See the Oxc mangling documentation and Terser API reference.

jQuery 3.7.1 · now smaller

Smaller than the official jquery.min.js.

The public-library row that used to be the honest loss: host-heavy, string keys, a plugin facade. Today the published ESM is 25,452 B Brotli against the official jquery.min.js at 27,445 B, and every delivered file is compiler-written with no minifier after it. The port is a reimplementation checked by its own compatibility suite and a names audit, not by jQuery’s upstream test suite.

marked 18 · parse API

Scored without the extension system.

The port implements marked 18.0.10’s Lexer, Parser, Tokenizer and Renderer, not use(). The bars run over the same parse-only sources: Oxc 10,092 B, Terser 10,138 B, esbuild 10,362 B, and SWC 10,031 B measured separately. The published ESM is 9,287 B Brotli, compiler-written, not post-minified.

Zod 4.4.3 · matched surface

A size claim again, on the surface both sides share.

The August claim was withdrawn because the port and the official entry exposed different surfaces. The bar is now zod 4.4.3 cut to the 181 z members the port shares, English locale only: Oxc 29,437 B, SWC 29,387 B. The package ESM is 28,132 B Brotli; about 1.2K of upstream core surface the port lacks is still in the bar, so the margin is roughly that size. Only zod.core.js is compiler-written; the 314 B compatibility file is hand-written and counted. The adapted official suite passes 1,353/1,353.

posthog-js 1.418.10 · kernel + 5 packs

The kernel beats Oxc; one pack still loses.

UUID, flag utils, cookie identity, request routing, rate limits, queue batching, bot detection and portable helpers — not the published PostHog IIFE. The kernel is 5,419 B Brotli against Oxc at 5,622 B and SWC with kept names at 5,482 B, a tie with SWC. On the lab’s five packs, autocapture, replay core and surveys win, OTLP ties, and error tracking still loses.

Not re-measured

Rows from the previous compiler, kept with their date.

The cards below were measured in August 2026 by the compiler route that was deleted on 23 September. Their labs need source migrations before the one compiler can rebuild them (Nano ID’s exports, for example, must not be constructible, and today an exported function keeps the callable kind its source declares), so they are shown as history, not as today’s result. The deleted route folded small closed programs harder than today’s compiler: on comparison/apps it wrote 558 B where today’s compiler writes 945 B and Closure ADVANCED 834 B.
