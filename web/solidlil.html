Experimental Solid 2 support.

The SolidLil library page contains the current package, three compression-objective builds, comparisons with the original and paired browser examples.

Compatibility coverage is not exact parity

The implementation includes LilScript modules and JavaScript providers. Scheduling, hydration, DOM and server semantics remain incomplete. Its measured bytes describe that compatibility runtime; they do not establish equivalent features or compiler-only savings.

The examples exercise selected signals, effects, stores, control flow and application interactions. The repository states the upstream target and the separate strict exact-port gate.
