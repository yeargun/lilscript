What the comparison measures

Raw counts uncompressed JavaScript bytes. gzip uses level 9; Brotli uses quality 11 and window 22. Original baselines select the smallest measured original artifact for each codec. A compressed winner need not be the raw winner.

The size boundary follows the linked library page: shared public exports, a selected subsystem, or the stated full SDK. CSS, fonts, type declarations, external dependencies and extra workers are outside a main-entry JavaScript measurement unless the page explicitly includes them. Compatibility runtimes and partial ports are identified.

Most original build times include bundling an installed upstream package and minification; they exclude building the upstream repository from source. PostHog records its source and delivery stages separately. Dependencies, tests and final transport compression are excluded. Measurements come from the hosts and dates recorded in each receipt.

Private property mangling and scalar replacement require proof or explicit source contracts. Download size does not establish parse speed or runtime speed. Runtime comparisons must use equivalent workloads, tested artifacts and the same browser or engine.
